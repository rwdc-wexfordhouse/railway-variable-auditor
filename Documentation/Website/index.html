Incident response tool

Every Railway variable, in one file.

On 21 October 2026 Railway disclosed that an unauthorised third party may have accessed encrypted environment variables and, for some of them, obtained the decrypted contents. Railway Variable Auditor helps you respond. It signs in to Railway, finds every workspace you can access, reads every variable on every service, and writes them, with their current values, to one CSV file. Then you work your way through it. Read Railway’s disclosure first.

How it works Checklist
What is built

The audit window and the audit command are written and tested against a fake Railway. They have not yet been run on the author’s live account. Run one yourself and check the result. The tool only reads. It never changes anything in Railway. It was called Railway Variable Cycler before it became an audit tool.

At a glance

One job: show you everything.

Rotating by machine proved too complex to trust during an incident. The tool now does the part that is safe and certain: finding and listing every variable, so nothing is missed.

Every workspace, automatically

One sign-in with the Railway CLI reaches every workspace you can access. You never pick them one at a time.

Read more →

One CSV, with the values

Workspace, project, environment, service, variable, value, and a category to help you sort. Readable by you only.

Read more →

Only reads, never hides a gap

Nothing is written to Railway. A workspace or project that cannot be read is named, with the reason, and the rest carries on.
