Overview  /  Windows
For administrators

Windows 11

A per-user setup program for the audit window and the audit command.

What has been tested

The Windows build is cross-compiled on Linux. It has been installed, run and uninstalled under Wine in a container, with a fake Railway CLI and invented data. It has not been run on Windows 11. Wine is not Windows. The setup program is not code signed. Treat this as a first build, and report what you find.

Before you install

  • Install the Railway CLI. Setup does not install it. Use npm i -g @railway/cli or scoop install railway, then sign in with railway login (or press Sign in with Railway in the window).
  • No administrator rights are needed. Everything goes into your own account.
  • Expect a SmartScreen warning. The installer is not code signed, so Windows says it does not recognise the publisher. Choose More info, then Run anyway, only if you trust where you got the file.

What Setup does

  1. Welcome and licence

    A short wizard shows the licence (GNU General Public Licence, version 3). You must accept it.

  2. Where to install

    The default is %LOCALAPPDATA%\Programs\Railway Variable Auditor. You can choose another folder.

  3. Options

    A Start menu folder (on by default), a Desktop shortcut (off), and adding the command line program railway-variable-audit to your PATH (on).

  4. Install

    The programs, the runtime they need, the licences and this website are written to the folder. An entry is added to Settings, Apps so you can uninstall it. No file types are registered, and nothing else on the computer is changed.

To remove it, use Settings, Apps, or the Uninstall Railway Variable Auditor shortcut. Uninstalling removes the files, the shortcuts, the Apps entry and the PATH entry. Audit files you saved are never touched.

What is different on Windows

  • The audit goes on your Desktop, as on Linux, in a new run-YYYYMMDD-HHMMSS folder.
  • The audit file is restricted to you with an access list instead of mode 0600. This has not been checked on a real Windows file system. Do not rely on it: keep the file on an encrypted disk, and delete it when you have finished (see Security).
  • File names and arguments are UTF-8, so names with accents come through.

The first Wine run found a real fault: the bundle was missing GLib’s two gspawn-win64-helper programs, so the audit could not start the Railway CLI. It is fixed, and the test now covers it.

Building the setup program

On Rocky Linux 10 (or another Red Hat Enterprise Linux 10 system with EPEL):

Support/windows/setup-toolchain.sh   # once: mingw64 compiler, meson, podman
make installer                       # build/RailwayVariableAuditor-0.1.0-setup.exe
make windows-test                    # the Wine smoke test (needs docker)
  • The libraries are MSYS2’s. GTK 4, json-glib and what they need are downloaded from the MSYS2 UCRT64 repository, and each file is checked against a SHA-256 hash pinned in Support/windows/msys2.lock. A file that does not match is refused.
  • The setup program is hand written. A small Win32 wizard (Source/windows/installer), with the files appended to it, compressed. There is no third party installer framework.
  • Licences travel with it. The licence text of every bundled package is installed under share\licenses. See THIRD-PARTY-NOTICES.md.
